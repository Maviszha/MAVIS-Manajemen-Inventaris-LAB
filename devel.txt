2. Keamanan (INI KRITIS)
Temuan

Query SQL menggunakan $conn->query() langsung
➜ rentan SQL Injection

Belum terlihat:

CSRF protection

Session hardening

Password hashing modern

Rekomendasi Wajib

Gunakan prepared statements

$stmt = $conn->prepare("SELECT * FROM user WHERE username=?");
$stmt->bind_param("s", $username);


Password hashing

password_hash($password, PASSWORD_BCRYPT);
password_verify($input, $hash);


Session security

session_regenerate_id(true);


Tambahkan:

CSRF token untuk form

Validasi input (server-side)

3. Autentikasi & Hak Akses
Temuan

Login terpisah di banyak file (login.php, loginbackup.php, dll)

Belum terlihat sistem role-based access

Rekomendasi

Satukan autentikasi ke 1 modul

Terapkan role:

Admin

Petugas Lab

Dosen

Mahasiswa

Contoh:

if ($_SESSION['role'] !== 'admin') {
  header('403');
}
